## การสร้างไฟล์สคริปต์ db-seeds

เราใช้ library ที่ชื่อว่า **Knex** เพื่อช่วยในการสร้างไฟล์สคริปต์ db-seeds (ข้อมูลตั้งต้น/ข้อมูลทดสอบ)  
โดย db-seeds จะใช้สำหรับ “ใส่ข้อมูล” ลงฐานข้อมูล เช่น role เริ่มต้น, admin user, ข้อมูลตัวอย่าง ฯลฯ

> หมายเหตุ: **migrations = เปลี่ยนโครงสร้างตาราง**  
> **seeds = ใส่ข้อมูลลงตาราง**

---

### การสร้างไฟล์ seed ใหม่

สร้างไฟล์ seed ใหม่ด้วยคำสั่ง:
```bash
npx knex seed:make <seed_name>
```

```bash
npx knex seed:run
```
